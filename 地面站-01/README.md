# 火箭远程点火基站

目标芯片为 STM32F103C8T6，Keil 工程为 `地面站-01.uvprojx`。

## 硬件连接

- 蓝牙模块接 U4：U4-1 是基站 RX，U4-2 是基站 TX，U4-3 是 GND，U4-4 是 5 V。需确认蓝牙模块 IO 电平与 3.3 V MCU 兼容。
- 图示三线按键模块为“按下高电平、松开低电平”：模块 `OUT` 接 H1-1（PB6），`GND` 接 H1-2，`VCC` 接 H1-4（+5 V），H1-3 不接。PB6 已改为下拉输入并按高电平判定按下。
- 一级点火 MOS 控制为 PC13，高电平有效，脉冲 800 ms。
- 三个状态灯为 PB3/PB4/PB5，高电平点亮。

## 发射流程

1. 两块板上电后，基站每 100 ms 发送一帧 PING。
2. 协议使用帧头、版本、序号、本次会话 token 和 CRC16-CCITT。必须连续 10 次序号正确的往返帧且飞控 IMU 就绪，才进入发射就绪。链路合格后允许最多 2 次连续响应丢失，第 3 次才撤销合格状态；超过 1 秒没有有效回复同样撤销。真正接受按钮发射时，最近一帧有效回复不得早于 250 ms。
3. 就绪后三个 LED 同时闪烁。`OUT` 必须先稳定保持低电平 100 ms，然后按下变为高电平并稳定 30 ms，以防止上电卡住造成误触发。
4. 有效按下时，基站立即打开一级点火 MOS，同时向飞控发送含 1400 ms 间隔的 LAUNCH 帧。LAUNCH 帧会重发最多 10 次，每次都带上一级点火后已过时间，用于飞控补偿丢包重发延迟；飞控用序号保证只执行一次。
5. 飞控回复接受后三灯常亮；未收到接受回复时三灯快闪报警。

## 台架验证

首次测试必须断开所有真实点火头，用万用表、逻辑分析仪或假负载核对 PC13 和飞控二级点火输出。蓝牙配对不等于链路已通过，只有三灯同步闪烁才表示协议自检通过。
