# 远程发射功能

## 接线

- 蓝牙模块接 H8：H8-1 是 USART2_TX/PA2，H8-2 是 USART2_RX/PA3，H8-3 是 5 V，H8-4 是 GND。蓝牙 TX 接 H8-2，蓝牙 RX 接 H8-1。
- 有源蜂鸣器正极接 H6-1（SERVO_6/PB11），负极接 GND。当前代码是高电平鸣叫，不适用于必须由方波驱动的无源蜂鸣器。
- 两个串口都是 115200-8-N-1。需确认蓝牙模块 IO 电平与 3.3 V MCU 兼容。

## 状态和安全逻辑

1. 上电后二级点火输出保持低电平，飞控继续完成 IMU 和气压计初始化。
2. 飞控只对帧头、版本、CRC16、递增序号和本次会话 token 都正确的 PING 回复 PONG。连续 20 帧正确才认为链路合格。
3. 链路合格且 IMU 累积至少 10 个正常样本后，蜂鸣器短响三次，然后长响表示就绪。发射前断链超过 500 ms 会取消就绪并停止蜂鸣。
4. 只有在就绪状态下，且 LAUNCH 帧的会话 token 和 6400 ms 间隔与本机配置相同时，才会接受发射。重发帧还带有“一级点火后已过毫秒数”，飞控用它补偿丢包重发延迟；重复 LAUNCH 帧只重复回复，不会重新开始倒计时。
5. 从接受 LAUNCH 的时刻起计时，6400 ms 时按原有 IMU/姿态联锁决定是否打开二级点火，脉冲宽度仍为 800 ms。点火后的燃尽检测、高度控制、姿态控制和开伞逻辑保持原样，但时间基准改为这次 LAUNCH 的起点。
6. 发射前的气压/速度滤波历史不带入飞行，20 秒飞行日志也从接受 LAUNCH 后才开始占用记录条数。

## 新旧启动方式

`Hardware/RocketConfig.h` 中默认为：

```c
#define ROCKET_REMOTE_LAUNCH_ENABLE         1
#define ROCKET_LEGACY_AUTO_LAUNCH_ENABLE    0
```

原来的“上电后固定延时点火”逻辑仍在 `RocketState.c` 中，只是默认失能。如果需要恢复旧模式，必须同时把远程模式改为 0，代码会在编译期防止两种启动源同时开启。

## 首次验证

第一次上电必须拔掉一、二级真实点火头，只用逻辑分析仪或假负载验证。应实测一级脉冲与 LAUNCH 发送同时、二级脉冲在飞控接收时刻后 6400 ms 开始，以及断链、坏 CRC、重复包和按键上电卡住都不会误触发。
